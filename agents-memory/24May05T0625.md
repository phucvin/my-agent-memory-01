# Summary
Implemented a rudimentary Lua to WebAssembly (WASM) compiler (`lua2wasm01`). The compiler uses `luaparse` to generate an AST from a subset of Lua code and traverses it to generate WebAssembly Text (`.wat`), specifically targeting standard math, conditional blocks, and functions using Wasm `f64`. A runner script was also created that utilizes `wabt.js` to compile the `.wat` file directly into a `.wasm` binary and executes it in Node.js.
